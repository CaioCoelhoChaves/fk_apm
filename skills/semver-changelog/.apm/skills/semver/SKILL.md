# /semver: Alias Rápido para Gerenciamento de CHANGELOG & SemVer

Alias rápido para o comando `/fk-semver-owner`. Permite manipular entradas em `## [Unreleased]`, categorizar alterações ou executar release bumps.

Exemplo de uso:
```bash
/semver Adicionar suporte a dark mode sob Added
/semver bump minor
```

Consulte a documentação completa em: [semver-changelog](../../SKILL.md).
